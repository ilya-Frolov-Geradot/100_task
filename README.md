# 100_task
Делаю 100 заданий по python

🟢 Элементарные задачи (1–25)
1. «Hello, World!» — вывести строку на экран.
2. Сумма двух чисел — запросить у пользователя два числа и вывести их сумму.
3. Чётное или нечётное — определить по введённому числу, чётное ли оно.
4. Факториал — рекурсивно и итеративно вычислить факториал n.
5. Калькулятор — простейший консольный калькулятор с операциями +, –, *, /.
6. Обратная строка — перевернуть строку, введённую пользователем.
7. Палиндром — проверить, является ли строка палиндромом.
8. Список квадратов — создать список квадратов чисел от 1 до n с помощью list comprehension.
9. Fibonacci — вывести первые n чисел последовательности Фибоначчи.
10. Максимум в списке — найти наибольший элемент без использования встроенной функции max().
11. Минимум в списке — аналогично, без min().
12. Удаление дубликатов — убрать дубликаты из списка, сохранив порядок.
13. Сортировка пузырьком — реализовать и протестировать bubble sort.
14. Подсчёт гласных — посчитать гласные буквы в строке.
15. Словарь с квадратами — создать dict, где ключи — числа, а значения — их квадраты.
16. Фильтрация — из списка отфильтровать только чётные числа с помощью filter().
17. Map & Lambda — применить анонимную функцию к каждому элементу списка.
18. Чтение файла — открыть текстовый файл и вывести его содержимое.
19. Запись в файл — записать в файл список строк.
20. Парсинг CSV — прочитать CSV-таблицу модулем csv и вывести первые 5 строк.
21. JSON-сериализация — сохранить и загрузить словарь в формате JSON.
22. Импорт/экспорт модулей — создать свой модуль и использовать его в основном скрипте.
23. Обработка ошибок — обернуть код в try/except и вывести понятное сообщение об ошибке.
24. Таймер — замерить время выполнения функции с помощью модуля time.
25. Генератор — написать функцию‑генератор бесконечной последовательности простых чисел.
