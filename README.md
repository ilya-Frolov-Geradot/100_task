# 100_task
Делаю 100 заданий по python
🟢 Элементарные задачи (1–25)

    «Hello, World!» — вывести строку на экран.

    Сумма двух чисел — запросить у пользователя два числа и вывести их сумму.

    Чётное или нечётное — определить по введённому числу, чётное ли оно.

    Факториал — рекурсивно и итеративно вычислить факториал n.

    Калькулятор — простейший консольный калькулятор с операциями +, –, *, /.

    Обратная строка — перевернуть строку, введённую пользователем.

    Палиндром — проверить, является ли строка палиндромом.

    Список квадратов — создать список квадратов чисел от 1 до n с помощью list comprehension.

    Fibonacci — вывести первые n чисел последовательности Фибоначчи.

    Максимум в списке — найти наибольший элемент без использования встроенной функции max().

    Минимум в списке — аналогично, без min().

    Удаление дубликатов — убрать дубликаты из списка, сохранив порядок.

    Сортировка пузырьком — реализовать и протестировать bubble sort.

    Подсчёт гласных — посчитать гласные буквы в строке.

    Словарь с квадратами — создать dict, где ключи — числа, а значения — их квадраты.

    Фильтрация — из списка отфильтровать только чётные числа с помощью filter().

    Map & Lambda — применить анонимную функцию к каждому элементу списка.

    Чтение файла — открыть текстовый файл и вывести его содержимое.

    Запись в файл — записать в файл список строк.

    Парсинг CSV — прочитать CSV-таблицу модулем csv и вывести первые 5 строк.

    JSON-сериализация — сохранить и загрузить словарь в формате JSON.

    Импорт/экспорт модулей — создать свой модуль и использовать его в основном скрипте.

    Обработка ошибок — обернуть код в try/except и вывести понятное сообщение об ошибке.

    Таймер — замерить время выполнения функции с помощью модуля time.

    Генератор — написать функцию‑генератор бесконечной последовательности простых чисел.
